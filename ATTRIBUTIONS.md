## 📝 How to Add New Sound Attributions

When adding open-source sound files requiring attribution (such as CC-BY or CC-BY-SA):
1. Add an entry to this file (`ATTRIBUTIONS.md`).
2. Add the corresponding card into [`public/attributions.html`](public/attributions.html).
3. Include the sound title, creator name, source URL, and license type.
